# Inggita Aryanta Inastu — Website Starter

Static website starter for deployment to cPanel.

## Files
- `index.html` — corporate homepage
- `puteri-anjani.html` — Puteri Anjani landing page
- `prana-living.html` — Prana Living landing page
- `assets/` — CSS, JavaScript and image directory

## Deploy to cPanel
1. Upload the ZIP contents (not the enclosing folder) into the domain's document root, usually `public_html`.
2. Ensure `index.html` is directly inside the document root.
3. Enable SSL/HTTPS in cPanel.
4. Test the homepage and both brand pages.

## Before public launch
Review and replace placeholder contact details, confirm the official company wording, add approved project and brand photography, and verify all email addresses and social links.
